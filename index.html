About

Projects

AngelAuraMC is built of a group of developers working together to bring new experiences for a game close to our hearts - Minecraft: Java Edition. Founded on principals of inclusion and collaboration, we aim to bring the game to greater heights and even more devices while making sure anyone feels free to create and share with us.

Amethyst is our prime launcher for Minecraft: Java Edition on Android and iOS. Built from the knowledge we gained from PojavLauncher (as well as new hands in the modding community), we strive to build an all-around great experience that you can carry in your pocket.

JudgeLib is a work-in-progress Minecraft: Java Edition API that makes it easy to build your own launcher projects from a battle-hardened base. Native- compiled for speed and memory efficiency, it's truly a "bring your own user interface, we'll handle the rest" foundation.
